# Saudi National Day

A Python project that recreates the Saudi national emblem as a futuristic neon-style animation using NumPy and Matplotlib.

## Features

* Programmatically generated palm tree and crossed swords
* Neon glow effect
* Animated drawing
* Arabic text
* Bézier curves for smooth shapes

## Requirements

* Python 3
* NumPy
* Matplotlib

## Installation

pip install -r requirements.txt


## Run

python main.py
